# 소스 읽기 실패 대응

| 실패 유형 | 대응 |
|-----------|------|
| WebFetch 타임아웃/네트워크 오류 | 1회 재시도. 재실패 시 사용자에게 URL 확인 요청 후 중단 |
| 페이월/로그인 필요 | 사용자에게 본문 텍스트 직접 제공 요청. 안내 메시지 출력 후 대기 |
| ar5iv 변환 실패 | Read tool로 PDF 직접 읽기 (pages: "1-20") 시도 |
| yt-dlp 트랜스크립트 없음 | 사용자에게 안내 후 중단 (트랜스크립트 없는 영상은 소스 불가) |
| HTML 구조 파싱 불가 | WebFetch prompt를 "전체 텍스트를 추출해 주세요"로 변경하여 재시도 |
