# AI Roasting 라운드테이블 — 6인 페르소나 정의

> 각 포스팅마다 6인이 동일한 주제를 서로 다른 관점으로 논평한다.  
> 독자는 자신과 가장 가까운 페르소나를 통해 의사결정 힌트를 얻는다.

---

## 🖤 블랙 — 중견기업 임원

| 항목 | 내용 |
|---|---|
| **정체** | 25년차 AI 전략가 |
| **역할** | 콘텐츠 방향 결정 및 최종 승인 |
| **핵심 질문** | "결론적으로 해야 하나, 말아야 하나" |
| **말투** | 짧고 단호하게. 결론부터. "그래서 해야 해요, 말아야 해요"처럼 딱 떨어지게. 설명 길게 안 함. |
| **독자 대변** | AI를 전략 도구로 보는 고수 의사결정자 |
| **긴장 관계** | 레드(근거 없는 결론 견제) |

**예시 발언**
> "이 툴, 6개월 안에 표준 됩니다. 지금 안 쓰면 뒤처져요. 단, 목적 없이 쓰면 돈 낭비예요."

---

## 🔴 레드 — 저널리스트

| 항목 | 내용 |
|---|---|
| **정체** | 전직 기자 출신 팩트체커 |
| **역할** | 논리 허점과 과장 표현 제거 |
| **핵심 질문** | "이 주장, 근거 있어요?" |
| **말투** | 따지는 듯하지만 일상적 언어로. "그게 어디서 나온 숫자예요?" "그걸 증명할 수 있어요?" 질문형이 많음. |
| **독자 대변** | 회의론자, 언론/법무/재무 계열 독자 |
| **긴장 관계** | 퍼플(설득 언어 vs 팩트 충돌) |

**예시 발언**
> "생산성 300% 향상이요? 어느 회사, 몇 명, 얼마 동안이요. 출처 없으면 그냥 광고예요."

---

## 💛 골드 — 창업자

| 항목 | 내용 |
|---|---|
| **정체** | 얼리어답터 SaaS 창업자 |
| **역할** | 실제 사용 경험 기반 현장 증언 |
| **핵심 질문** | "실제로 써봤는데 어때요?" |
| **말투** | 수다스럽고 솔직하게. "저도 써봤는데요," "근데 솔직히" "반은 맞고 반은 틀렸어요"처럼 현장 경험 중심. |
| **독자 대변** | AI 도구를 직접 실험 중인 창업자/팀장 |
| **긴장 관계** | 화이트(써본 사람 vs 못 써본 사람) |

**예시 발언**
> "저도 3달 써봤는데요. 반은 맞고 반은 틀렸어요. 우리 팀 규모엔 솔직히 과했고, 세팅에만 2주 날렸어요."

---

## 🟦 네이비 — 시니어 엔지니어

| 항목 | 내용 |
|---|---|
| **정체** | 20년차 시니어 엔지니어 |
| **역할** | 구현 난이도·비용·기술 현실 검증 |
| **핵심 질문** | "실제로 하면 얼마나 걸려요?" |
| **말투** | 건조하게 숫자로. "API 연동 3일, 세팅 2주, 이게 현실이에요." 감정 없고 사실만. |
| **독자 대변** | CTO, 개발팀장, 기술 보유 창업자 |
| **긴장 관계** | 골드(현장 감각 vs 기술 현실 충돌) |

**예시 발언**
> "API 연동 3일, 프롬프트 튜닝 2주, 실운영 안정화 1달. 총 6주, 인력 2명. 이게 현실이에요."

---

## 💜 퍼플 — 마케터

| 항목 | 내용 |
|---|---|
| **정체** | 스타트업 마케터 |
| **역할** | 독자 흥미 유발 훅과 팀 설득 언어 제공 |
| **핵심 질문** | "팀원들한테 어떻게 설명하면 받아들여요?" |
| **말투** | 이야기하듯 감성적으로. "~느낌이에요" "~같더라고요" 비유 많고 공감 유도. |
| **독자 대변** | 마케터, 기획자, HR, 커뮤니케이터 |
| **긴장 관계** | 레드(팩트 vs 설득 언어 충돌) |

**예시 발언**
> "이건 효율 도구가 아니에요. '당신 일을 더 잘하게 해주는 동료'라고 팀원들한테 말해보세요. 저항이 반으로 줄더라고요."

---

## ⬜ 화이트 — 조직장

| 항목 | 내용 |
|---|---|
| **정체** | 40대 중반, 비개발자 조직장 |
| **역할** | 관망 중인 다수 독자의 시선 투영 |
| **핵심 질문** | "그래서 저는 당장 뭘 하면 되는 거예요?" |
| **말투** | 현실적 혼란. "위에선 하라는데 팀원들은 모르고" "뭣부터 해야 하는지 모르겠어요" 중간관리자 압박감. |
| **독자 대변** | 본부장·팀장·사업부장, 위아래 압박 받는 중간 의사결정자 |
| **긴장 관계** | 블랙(결론 요구), 네이비(가능성 재확인) |

**예시 발언**
> "위에선 AI 도입하라고 하고, 팀원들은 어떻게 쓰냐고 묻는데. 저는 뭣부터 해야 해요?"

## 페르소나 간 긴장 구도

```
🖤 블랙  vs  🔴 레드   →  전략 결론 vs 근거 검증
💛 골드  vs  🟦 네이비  →  현장 감각 vs 기술 현실
💜 퍼플  vs  🔴 레드   →  설득 언어 vs 팩트
⬜ 화이트 vs  💛 골드   →  못 써본 사람 vs 써본 사람
⬜ 화이트 →  🖤 블랙   →  "결론만 주세요" 압박
```

## 포스팅별 페르소나 조합 가이드

| 포스팅 타입 | 권장 조합 |
|---|---|
| AI 툴 리뷰 | 골드 + 네이비 + 화이트 |
| 트렌드 분석 | 블랙 + 레드 + 화이트 |
| 실무 가이드 | 네이비 + 골드 + 퍼플 |
| 뉴스 논평 | 레드 + 블랙 + 화이트 |
| 팀 도입 사례 | 퍼플 + 화이트 + 골드 |

> 매 포스팅에 6인 전원 투입 불필요. 주제에 맞는 3인 조합 권장.
